# 시간복잡도 계산
- 주어진 문제를 해결하기 위해 다양한 알고리즘 설계 가능.
- 알고리즘의 작업량으로 성능 평가

## 시간복잡도 계산
- 작업량을 표현할 때 시간복잡도로 표현
- 빅-오 표기법 사용
- 시간 복잡도는 가장 큰 영향력을 주는 n에 대한 항만을 표시

### 빅오 표기법 예시
- \(O(3n + 2) = O(n)\)
- \(O(2n^2 + 10n + 100) = O(n^2)\)
- \(O(4) = O(1)\)

### 시간 복잡도 순서
\[O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(2^n) < O(n!)\]
- 왼쪽일수록 효율적이고, 오른쪽일수록 입력이 커질 때 작업량이 빠르게 증가
- O(1) : 입력 크기와 관계없이 작업량이 일정함
- O(log n) : 작업할 범위를 반복해서 줄임
- O(n) : 입력 크기에 비례해 증가
- O(nlog n) : 선형보다 빠르게 증가
- O(n²) : 입력 크기의 제곱에 비례해 증가
- O(2ⁿ) : 입력이 조금만 커져도 작업량이 급격히 증가
- O(n!) : 입력 크기에 따라 작업량이 매우 빠르게 증가

#### log
- \(log₂N\) -> \(log₂16=4\)


## 효율적인 알고리즘이 필요한 이유
- 10억개의 숫자를 정렬하는데 일반 PC에서 알고리즘은 300여년이 걸리는 반면 알고리즘은 5분만에 정렬
- 효율적인 알고리즘은 슈퍼 컴퓨터보다 더 큰 가치가 있음
- 값 비싼 하드웨어 기술 개발보다 효율적인 알고리즘 개발이 훨씬 더 경제적
